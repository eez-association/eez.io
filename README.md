# eez.io

The eez.io website: one static site on GitHub Pages.

Preview: https://eez-association.github.io/eez.io/

## Pages
- `/`: Home
- `/use-cases/institutions`, `/chains`, `/apps`, `/infra`: use cases by audience
- `/use-cases/all`: every use case
- `/use-cases/scoping`, `/use-cases/kit`: joining steps, integration kit
- `/get-in-touch`: contact form
- `/brand`: logo downloads
- `/media`: press and talks
